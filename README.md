# SIP by inVino.io
- Restaurant's food is banging, and they wine list is eclectic, but there is no on to pair things up for you? Scan the menus, and set the sommelier in your pocket to work.
- Introducing SIP the OWL, your Somm-in-Palm
- A web app with RAG and OpenAI to suggested wine pairings to elevate your dining experience

## Development Setup
- Make sure pg_config is installed, less the deps for which will not install on Fedora:

```
sudo dnf install postgresql-devel
which pg_config
```
